{% if values.get('source_job') %} {% endif %}

Le vérificateur est strict : il rejette tuplets, ornements et accords hors vocabulaire natif. « Retirer les accords » valide avant et après, et garantit que la mélodie est intacte. La comparaison est l'invariant à contrôler après une réharmonisation : mêmes notes, seuls les accords changent.

Quand fournir une partition ?

{{ P.PANEL_HELP.plan_only }}

Pour une reprise : partez d'une partition sans symboles d'accords et choisissez le mode melody. Pour une réharmonisation : gardez la mélodie, changez les accords entre guillemets et choisissez le mode full. Le vocabulaire d'accords natif est : majeur (sans suffixe), m, dim, aug, 7, maj7, m7, dim7, m7b5, sus4, sus2, 6, m6, 7sus4, m(maj7), avec basse optionnelle (ex. F#m7/C#).
